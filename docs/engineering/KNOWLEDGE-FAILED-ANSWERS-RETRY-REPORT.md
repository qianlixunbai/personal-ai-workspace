# 资料逐份问答：仅重新准备失败项

2026-11-11，分支 `codex/knowledge-version-compare`，实现前 HEAD `521264e`。

## 行为变化

逐份资料问答出现部分失败时，原先只能重新准备整个所选范围，容易把成功资料重复提交。现在整轮处理结束且每个请求状态明确后，可选择“仅重新准备失败项”。

- 新清单只包含明确 FAILED、CANCELLED、TIMED_OUT 或请求未受理的资料；成功项排除。
- 尚未提交、正在提交、运行中、原任务待核对或提交结果未知时，不提供该入口。状态未知不会通过历史相似结果猜测或重新提交。
- 使用原批次的问题、关键词及每份资料的 documentId/sourceRevision；后来更改检索范围或版本不会改变重试范围。
- 确认弹窗列出资料标题与版本。取消后保留原结果；确认只替换页面清单，随后还需点击“确认清单并逐份回答”才产生新请求。已保存历史不改写。
- 离开页面或服务不可用时关闭确认框，沿用已有暂停与连接会话清理行为。

改动仅涉及 `KnowledgeSourceAnswers.tsx` 及其测试，复用现有单资料问答接口和确认组件，无后端、协议或数据库迁移。
