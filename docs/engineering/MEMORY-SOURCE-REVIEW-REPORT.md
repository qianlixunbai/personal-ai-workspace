## 数据、身份和预算

出处仍是可编辑文字，只能作为用户主动查找的定位线索。界面明确说明：即使某段正文与某个指定来源逐字一致，也不证明原始来源关系或事实真实性。没有新建持久关联、迁移 schema、改写已保存记忆或自动选择模型上下文。

`memoryKnowledgeSource.ts` 复用原出处输出格式，识别一个完整 LF 格式记录。多处出处、格式损坏、无效 UUID、版本或范围不明确时不猜测、不查询。保留 `41cb53a` 已生成的格式，不要求重新保存旧记录。无识别标记的普通 Memory 不增加回查区；手动改坏出处后需要先核对文字，不能宣称所有自由文本都有可自动解析的来源。

原文范围不超过原预览的 4096 UTF-16 单位，最多跨 16 个连续分节读取，整体 30 秒检查窗口；单次 Bridge 请求沿用原超时。文本只在完整读回且字符边界有效后发布，不把前缀当作完整核对结果。上下文导航一次一页，最多保留 32 个页偏移。读取不完整、异常版本、范围越界或切断 Unicode 字符时不发布对照结果。

正文变化、编辑对象代次、不可用／离页、收起或会话重置使待回执失效，旧详情返回后不会继续跨上下文读取来源。每次请求仍经过原 WorkspaceClient 的会话、请求 ID、文档 ID、源版本、偏移和信封校验；没有新 Native／Runtime API 或 Browser 权限。没有模型生成、隐式 Memory 写入、自动重试／更新、索引重建、外部网络或用户资料操作。
