# 记忆搜索结果的只读预览

2026-11-07，开发基线 `623bd8a`。依据用户要求改善日常记忆使用，并遵守 ADR-004 的用户主动维护、显式选择和无自动提取边界。本阶段交付只读预览，不声明自动长期记忆。

## 实际功能与范围

“我的记忆”中可点击一条结果的“预览正文”，在列表内查看完整标题、正文和已提交搜索词的高亮。一次只展开一条，只有用户点击才调用既有 `memory.get`，不预取全页正文。右侧未保存编辑不被替换，也不因预览触发丢弃确认；若要进入编辑，仍沿用原有未保存保护。

高亮按当前搜索合同执行区分大小写的字面子串匹配。输入框中新输入但尚未提交的搜索词不改变已有结果的高亮。保存内容及查询均作为 React 文本节点，未用 HTML 注入、正则解释、摘要或截断；换行完整保留。预览不改变检索排序或筛选规则，不自动保存、归档、选择为上下文或调用模型。

读取结果须与列表条目的 ID、revision 和状态一致；已修改、归档等版本变化要求刷新列表再预览，不将新正文冒充旧搜索结果。读取失败只显示安全错误，不自动重试。收起、改预览项、刷新／筛选、离页、禁用或切换 session 会清除预览；关闭后到达的响应不会重新显示。正文只在当前组件内存中保留，不写 URL、浏览器持久存储或日志。

改动限于新增 `MemoryPreview.tsx`、`MemoryPage.tsx` 的展开状态及 CSS。API、Native Bridge、Java、schema、真实数据和系统配置未更改。
