# 问答出处与跨页参考的读取恢复

日期：2026-11-11。基线 `e5c4778`。

## 证据与修复

`WorkspaceKnowledge.AnswerHistoryAsync` 只授予当前历史页的记录；下一次列表调用替换 `HistoryPage`。`AnswerHistoryGetAsync` 要求 ID 属于这一页。此前 `readAnswerSource` 直接读取可编辑出处中的 ID，因此重开应用后从记忆回查、选中上一页参考后翻页再核对，都可能被原生正确拒绝。原合成夹具没有模拟这条授权合同；其旧通过结果不证明原生流程可用。

现在共用 `readAuthorizedAnswerHistory`：最多读取现有 50 页／1000 条受控历史摘要，找到完全相同的 ID 后才读取原问答；不读其他回答正文、不按相似问题替换、不尝试未出现的 ID。每步检查会话／编辑代次以及 30 秒观察期限。列表变化、超时或原记录缺失保持失败，不自动重试、提交或恢复权限。列表不是一致快照，并发翻页仍可能使原生拒绝；失败安全保留草稿。

记忆中的问答出处、回答摘录核对、跨页待选会话参考及历史阅读均复用此方法。读取仍核对任务 ID、原回答、固定来源版本与选区；原生授权和持久化格式没有变化。跨页读取只影响 Native 的临时授权页，不替换用户看到的列表或编辑草稿。
