## 使用方式与范围

此前 Knowledge 成功回答已有“整理为记忆草稿”入口，原文预览没有对应操作，用户只能另行复制粘贴。现在打开资料的任一已发布源版本，在本页原文中选择文字，点击“将选中原文整理为记忆草稿”，进入已有 Memory 编辑器。草稿完整带入所选文字及资料名称、ID、源版本、起止偏移；用户填写标题、检查、修改，再点击“保存”。取消替换已有草稿时原草稿保留。

所选内容是已验证原文的精确切片，不要求先生成知识回答或模型候选。高亮节点与普通文字可以一起选择，非零预览偏移会换算为该源版本的绝对位置。选区必须完全属于当前预览，不能为空或拆开 Unicode 代理对；切换版本、不可用状态、离页及会话重置使选区失效。仅支持当前预览页的连续选区，不跨页自动收集原文。

资料来源以本次草稿的 `KNOWLEDGE` 角色区分于 USER／ASSISTANT，避免把原文称为助手回复或用户陈述；该角色不进入持久化协议。出处是可编辑的正文文字，不是 Runtime 绑定的引用，不自动同步资料更新或提供可点击回查。保存仍是原有 MANUAL 记忆，内容真实性由用户核实。资料或出处使正文超限时完整保留，禁止保存并提示修改，不截断原文。

保存后，可沿已有记忆列表／编辑入口重开，之后通过原有问答／会话的原生选择器主动选择才会用作上下文。本轮没有改变这些使用权限，没有自动保存、自动选择、模型生成、后台资料读取、索引重建、自动回放或新增依赖／API／schema。原有 Memory 草稿冲突、未知写入和 Native 未保存通知路径保留。
