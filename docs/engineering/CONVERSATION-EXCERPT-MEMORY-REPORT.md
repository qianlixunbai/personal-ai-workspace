# 历史对话摘录到可回查记忆

2026-11-10，基线 `67b6b8501df8787deb755bfca869156ad9afe1de`。本会话第二个完整模块：从历史长消息选择片段，预览带精确出处的记忆草稿，明确送入编辑器并手动保存，以后从记忆正文主动回查原消息及整轮上下文。

## 缺口与交付

原会话页只能把整条消息复制到记忆草稿：长回复常超过 Memory 限制，且没有留下原会话、轮次与消息的位置。已有资料出处回查只处理 Knowledge 文档，不能回到产生笔记的历史对话。

- 终结轮次中的用户消息和已保存的助手回复增加“摘录并保留对话出处”。打开后显示原消息的纯文本，可用鼠标／键盘选择片段或明确选择整条消息，预览完整草稿与长度。超过现有 Memory 限制、Unicode 被切断或出处标记有歧义时不能送入；不截断正文或省略出处。
- 草稿包含所选正文、显示标题、会话 ID、轮次 ID／序号、消息 ID／角色及精确 UTF-16 偏移。标题中的换行仅在定位说明中合并为空格，原消息片段保持逐字不变。
- 点击“核对原消息并送入记忆草稿”时，仅按指定轮次所在页调用一次现有 `conversations.get`，核对三个标识、轮次、角色、范围和选中原文。失败不写草稿，不转查最新轮次，也不自动重试。
- 沿用真实 Memory 编辑器的未保存修改确认。取消保留原记忆草稿及当前未发送问题；接受后仍须填写标题、审阅并点击保存。既有整条消息转普通草稿入口保留，未改变其行为。
- 记忆编辑器、只读预览、工作区查找中的记忆阅读以及版本一致的会话记忆引用，共用扩展后的 `MemorySourceReview`。含完整对话出处时提供“查看对话出处”，不自动读取；读取后对照所记范围，可展开原轮次的用户消息／助手回复。改名或归档可只读回查，身份缺失／范围无效／删除则明确失败。
- 编辑正文、禁用页面、切换会话、收起或卸载会使在途读取失效，迟到回执不能送入新草稿或显示为新出处。正文被人工修改时显示不一致，不替换记忆；出处后的批注不参与比较。

## 边界

主要代码为 `ConversationExcerptMemory.tsx`、`memoryConversationSource.ts`、`ConversationSourceReview.tsx`，只在现有会话页和统一出处组件接线，并澄清 Memory 的来源文案。没有新增 Runtime／Native API、数据库 schema、权限、文件写入或持久化协议。

出处始终是用户可编辑的正文定位线索，不是受信来源关联，也不证明最初来源、历史真实性或助手结论正确。保存仍是 MANUAL；草稿来源角色不额外持久化。历史轮次中的记忆选择不会被恢复、自动选入或发送给模型。此次工作未执行任何真实模型请求，也未修改已有显式模型操作的权限。
