# 多资料检索的切页保留与明确继续

日期：2026-11-11。源码基线 `fb998d4ab3fd6a70a0469c5fb91881693dab0380`。

## 缺口与改动

核对批量导入、逐份问答及 App 页面挂载方式后，确认两种任务流程已有切页暂停和原回执保留；但 `KnowledgeSearch` 在 `visible=false` 时调用完整清空，丢失关键词、最多 10 份明确版本的清单以及已完成分组。用户前往记忆或对话后回来，必须重新选择并查询整组资料。本项处理这一使用缺口，不重复增加任务或恢复设施。

现在切页、页面不可用或主动“暂停后续检索”只停止后续读取，使当前在途结果失效；关键词、明确范围、成功结果和未完成分组保留在原连接会话内。返回不自动发起资料检索。用户可“继续未完成查询”，只查询失败或尚未完成的分组；已成功的分组（包括零命中）不重复查询，资料 ID、版本和关键词保持原样。原有“检索”仍明确重查全部当前所选资料。

暂停不表示已取消在途只读请求；其迟到回执不参与后续结果。结果呈现继续区分成功、零命中、失败和未查询，旧片段保留准确版本及位置，能够打开原文。页面说明这些是各次查询结果，没有同一时刻快照或自动更新保证。

修改关键词、改变范围、刷新资料集合或索引失效会使旧结果及继续入口失效，不能把原组结果混入新条件。资料集合刷新仍保留草稿和明确版本，并提示重新检索；不会自动改用新版或全库。连接会话更换仍清空临时内容，也隔离旧索引状态响应，并为新会话重新读取状态。同步动作锁避免同一操作重复启动。

没有改变批量导入／问答的请求或任务身份，没有自动发送问题、上传资料或持久化浏览器数据。关闭应用或连接会话更换后的检索草稿恢复不在本次范围内；既有导入回执和问答历史的跨重开边界保持原合同。

## 最少验证

- 覆盖切页后清单／关键词／成功结果保留、不自动重查、仅继续未完成分组、当前文档已更新时仍请求原版本、精确原文定位、主动暂停、资料集合／关键词／范围失效、session 轮换和旧状态失败隔离。
- 本次涉及组件状态与查询入口变更，`tsc --noEmit` 通过；Git 差异空白检查通过。没有先失败再放宽产品或测试合同的情况。
