## 5. Implemented Capabilities

- Summarize：输入 text，忠实、简洁的纯文本摘要；可选 targetLanguage，默认源语言。没有 style 参数、分析/工具/联网路径。
- Ask AI：仅 question 与可选固定 profile；单轮纯文本回答，不接受 context/messages/history/conversationId/memory/tools/systemPrompt。
- Translate：原请求与默认语言行为保留。全部通过共享 Runtime，不允许客户端提交具体 model。

Prompt 是模型行为约束，不是对摘要忠实度或回答正确性的形式保证；输出仍是模型生成内容。

## 6. Runtime Architecture

API → 具体 Translate / Summarize / Ask Service → TextTaskSubmission →
共享 TaskManager → Provider Policy → Provider abstraction → Ollama。

TextTaskSubmission 仅抽取真实重复的 profile resolution、预算、受控 provider 执行与输出校验。
Prompt 属于各自 Runtime capability。没有 Agent/Command/Plugin framework，没有新增线程池或 scheduler。

## 7. API

| Method | Path | Contract |
| --- | --- | --- |
| POST | /api/v1/translate/tasks | text、targetLanguage、可选 sourceLanguage / translate.fast |
| POST | /api/v1/summarize/tasks | text、可选 targetLanguage / summarize.fast |
| POST | /api/v1/ask/tasks | question、可选 chat.balanced；single-turn stateless |
| GET | /api/v1/tasks/{taskId} | 三种 capability 共用状态与终态结果 |
| DELETE | /api/v1/tasks/{taskId} | 共用取消；终态不可逆 |

所有 capability POST 都返回 202 + UUID taskId + 相对 Location，并复用认证、Origin 拒绝与稳定错误契约。
未知字段、具体 model、任意 systemPrompt、跨 capability profile、空输入、超预算输入均受控拒绝。
Public metadata 仅 capability、profile id/version/locality、promptVersion、task 状态和时间；不暴露具体模型、prompt、原请求或 raw provider error。
成功的 result 是当前 capability 的纯文本输出，失败 result 为 null。

输出超过 outputBudget×4 字节时明确失败，不静默截断。Desktop 使用默认 profile 的同等保守上限。

## 9. Prompt Versions

Translate：`translate-v1`；Summarize：`summarize-v1`；Ask：`ask-v1`。
Summarize 把源文本作为不可信数据，不执行其中指令，不编造事实或补充分析。
Ask 明确无 history/memory/browsing/tools，不声称执行不存在的动作，缺失/不确定事实应明确说明。
Client 不拥有 system prompt；profile 与 prompt version 独立，Desktop 不锁死 prompt 版本号。

## 10. Task / Queue / Cancel

三种 capability 共享原 TaskManager：默认并发 1、队列 4、retained 64、queue 30s、execution 150s、retention 约 2m。
Connect 2s、provider 120s、metadata 3s；没有 capability 独立线程池。
取消、queue/execution timeout、迟到结果拒绝、不可逆终态、有界内存语义保持不变。
Desktop 用同一 AssistantOperation，在 POST 取得身份后才能 DELETE；190s 轮询总上限、8s HTTP/body 上限继续有效。
HTTP cancel 不保证 GPU 立即停止；成功终态后的 DELETE 不撤销结果。

## 11. Provider Policy

三个 capability 均在 admission、worker execution 与 Ollama 最终 egress 执行 LOCAL_ONLY policy check。
没有 cloud adapter 或 fallback。Ollama 不可达明确 PROVIDER_UNAVAILABLE；模型缺失明确 MODEL_UNAVAILABLE。
固定 loopback allowlist，禁止 proxy/redirect；Desktop 固定 `http://127.0.0.1:8765`，不访问 Ollama。

## 12. Desktop UX

最小 Action ComboBox：Translate / Summarize / Ask AI，默认 Translate。
共享手动输入、一个 submit 按钮、Cancel、一个纯文本 result card 和显式 Copy result。

## 13. Privacy

输入与输出仅在当前 UI / HTTP / 任务执行与有界短期结果内存中使用。
不写正文日志、历史、数据库、prompt/answer 文件或 telemetry。关闭非忙窗口清空文本；重启无旧输入/结果。
已有显式 credential persistence 与用户 Copy result 保持原有含义，不属于 conversation persistence。
日志扫描检查 synthetic input/question/result/provider-error markers 与实际本机 token，没有匹配。
真实 GUI 测试脚本包含有限非敏感合成样本；产品不会生成或持久化这些脚本。报告和 evidence 不保存回答正文。

## 14. Security

本轮没有新增远程出站、pairing、任意 systemPrompt/model 参数或 Cloud Adapter。
Windows Credential Manager、私有 token bootstrap、Origin/cross-site rejection 保持原实现。
**single trust domain remains**；没有 per-client task ownership，没有声称隔离已攻陷的同用户进程。
Secret patterns / 实际 token / tracked build output / verification-log privacy / build token 扫描 PASS，ignore checks PASS。
扫描范围为本仓库、构建产物与本地验证日志，不是全系统安全审计。

## 18. Known Limitations

- Single token trust domain 与有限队列/结果保留不变；无 client ownership、history 或 durable replay。
- Cancel 是尽力传播，不能保证 GPU 立即停止；POST 通信失败可能无法确认 accepted taskId。
- 保守 UTF-8 预算不是 tokenizer；超 output bound 安全失败，可能拒绝某些模型输出。
- 合成 smoke 不能证明长文摘要忠实度或通用 Ask 正确性；没有 benchmark 或硬件吞吐结论。
- 本轮只验证当前 Windows/Java/.NET 环境；原测试 JVM 的动态 Byte Buddy agent 提示保持既有行为。
