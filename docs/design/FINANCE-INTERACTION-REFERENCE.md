## Workspace 决策

- FinancePage 管理一次性、类型化 Intent，明确 source/target/filters/selection；只保留有限返回条件，不缓存金融响应、不新增 hash/Router。
- Dashboard 卡片使用语义 button；净额和月份在原页面展开权威字符串详情。SVG 仍只使用服务端坐标；独立月份按钮支持 Tab、Enter/Space、选中和关闭。
- Transactions 复用原组件、固定 Bridge 方法、服务端分页及 kind/id 详情查询。月度 scope 强制普通 CNY INCOME/EXPENSE，月初 inclusive、下一月初与 Dashboard asOf 的较早值 exclusive。
- 返回重新请求；Finance 卸载、Session/Runtime/身份失效清除 Intent、选择与返回条件，generation 拒绝迟到响应。保留 App MemoryLeaveGuard。
- 投资只增强导航，沿用 Position → History 的 positionId、原 Receipt/Correction/Audit，不做任何行情或金融写入。
